# Инструкция по установке Snapchat AI Bot

## 🚀 Быстрый старт

### 1. Установка расширения в Chrome

1. **Откройте Chrome** и перейдите в `chrome://extensions/`
2. **Включите "Режим разработчика"** (Developer mode) в правом верхнем углу
3. **Нажмите "Загрузить распакованное расширение"** (Load unpacked)
4. **Выберите папку `dist`** из проекта
5. **Расширение установлено!** 🎉

### 2. Настройка Firebase

1. **Создайте проект** в [Firebase Console](https://console.firebase.google.com)
2. **Включите Firestore Database**:
   - Перейдите в "Firestore Database"
   - Нажмите "Создать базу данных"
   - Выберите "Начать в тестовом режиме"
3. **Получите конфигурацию**:
   - Перейдите в "Настройки проекта" → "Общие"
   - Скопируйте конфигурацию веб-приложения

### 3. Настройка OpenAI

1. **Получите API ключ** в [OpenAI Platform](https://platform.openai.com)
2. **Создайте API ключ**:
   - Перейдите в "API Keys"
   - Нажмите "Create new secret key"
   - Скопируйте ключ

### 4. Первоначальная настройка

1. **Откройте админ панель**:
   - Нажмите на иконку расширения
   - Выберите "Настройки"
2. **Настройте Firebase**:
   - Вставьте конфигурацию Firebase
   - Нажмите "Тест подключения"
3. **Настройте OpenAI**:
   - Вставьте API ключ OpenAI
   - Выберите модель (рекомендуется GPT-3.5-turbo)
   - Нажмите "Тест подключения"
4. **Создайте ИИ агента**:
   - Перейдите в "ИИ Агенты"
   - Нажмите "Создать агента"
   - Заполните данные агента
5. **Включите бота**:
   - Вернитесь в "Настройки"
   - Включите "Включить бота"
   - Сохраните настройки

## 🔧 Детальная настройка

### Firebase структура данных

Расширение создаст следующие коллекции в Firestore:

```
chatSessions/
├── {sessionId}/
│   ├── id: string
│   ├── chatId: string
│   ├── messages: ChatMessage[]
│   ├── lastActivity: timestamp
│   ├── isActive: boolean
│   └── aiAgentId: string

aiAgents/
├── {agentId}/
│   ├── id: string
│   ├── name: string
│   ├── personality: string
│   ├── systemPrompt: string
│   ├── isActive: boolean
│   ├── createdAt: timestamp
│   └── updatedAt: timestamp

statistics/
└── main/
    ├── totalMessages: number
    ├── totalReplies: number
    ├── activeChats: number
    ├── averageResponseTime: number
    ├── successRate: number
    └── dailyStats: DailyStats[]
```

### Настройка правил безопасности Firestore

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Разрешаем чтение и запись для аутентифицированных пользователей
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

### Настройка OpenAI

**Рекомендуемые параметры:**
- **Модель**: `gpt-3.5-turbo` (экономично) или `gpt-4` (качественно)
- **Макс. токенов**: 500-1000
- **Температура**: 0.7 (баланс креативности и предсказуемости)

## 🎯 Использование

### Основные функции

1. **Автоматические ответы**:
   - Бот отслеживает новые сообщения
   - Анализирует их с помощью ИИ
   - Генерирует и отправляет ответы

2. **Управление агентами**:
   - Создавайте разных ИИ агентов
   - Настраивайте их личности
   - Переключайтесь между агентами

3. **Статистика**:
   - Отслеживайте активность
   - Анализируйте эффективность
   - Просматривайте логи

### Настройка ключевых слов

Добавьте слова, на которые должен реагировать бот:
- `привет`, `hello` - приветствия
- `как дела`, `что делаешь` - вопросы о состоянии
- `помоги`, `help` - просьбы о помощи

### Исключенные пользователи

Добавьте пользователей, которым бот не должен отвечать:
- Служебные аккаунты
- Боты
- Нежелательные контакты

## 🐛 Устранение неполадок

### Бот не отвечает

1. **Проверьте статус**:
   - Убедитесь, что бот включен
   - Проверьте активного агента
   - Посмотрите логи

2. **Проверьте подключения**:
   - Firebase подключение
   - OpenAI API ключ
   - Интернет соединение

3. **Проверьте настройки**:
   - Ключевые слова
   - Исключенные пользователи
   - Задержка ответа

### Ошибки в консоли

1. **Откройте DevTools** в Snapchat
2. **Перейдите в Console**
3. **Найдите ошибки** с префиксом "Snapchat Bot"
4. **Проверьте логи** в админ панели

### Проблемы с Firebase

1. **Проверьте правила безопасности**
2. **Убедитесь в правильности конфигурации**
3. **Проверьте права доступа**

### Проблемы с OpenAI

1. **Проверьте API ключ**
2. **Убедитесь в наличии средств на счете**
3. **Проверьте лимиты API**

## 📊 Мониторинг

### Статистика в реальном времени

- **Активные чаты**: количество текущих диалогов
- **Сообщения**: общее количество обработанных сообщений
