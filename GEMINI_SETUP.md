# Настройка Google Gemini API

## 🆓 Бесплатный API от Google

Google Gemini предоставляет **бесплатный** API с щедрыми лимитами:
- **15 запросов в минуту**
- **1 миллион токенов в день**
- **32,000 токенов за запрос**
- **Без ограничений по времени**

## 🔑 Получение API ключа

### Шаг 1: Перейдите в Google AI Studio
1. Откройте [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Войдите в свой Google аккаунт
3. Нажмите **"Create API Key"**

### Шаг 2: Создайте API ключ
1. Выберите проект (или создайте новый)
2. Нажмите **"Create API Key"**
3. Скопируйте сгенерированный ключ

### Шаг 3: Настройте расширение
1. Откройте админ панель расширения
2. Перейдите в раздел **"Google Gemini настройки"**
3. Вставьте API ключ в поле **"API Key"**
4. Нажмите **"Тест подключения"**

## ⚙️ Рекомендуемые настройки

## 📊 Лимиты и ограничения

### Бесплатные лимиты
- **15 запросов в минуту** - достаточно для личного использования
- **1M токенов в день** - очень щедро
- **32K токенов за запрос** - хватит для длинных диалогов

### Рекомендации по использованию
- Используйте **Gemini 1.5 Flash** для быстрых ответов
- **Gemini 1.5 Pro** для сложных задач
- Настройте **задержку ответа** 2-3 секунды
- Мониторьте использование в статистике

## 🔧 Настройка параметров

### Temperature (0.0 - 2.0)
- **0.0** - детерминированные ответы
- **0.7** - баланс креативности и предсказуемости (рекомендуется)
- **1.0+** - более креативные ответы

### Top P (0.0 - 1.0)
- **0.8** - хороший баланс (рекомендуется)
- **0.9** - более разнообразные ответы
- **1.0** - максимальная креативность

### Top K (1 - 100)
- **40** - оптимальное значение (рекомендуется)
- **20** - более предсказуемые ответы
- **60** - более разнообразные ответы

## 🛠 Устранение неполадок

### Ошибка "API Key invalid"
1. Проверьте правильность ключа
2. Убедитесь, что ключ активен
3. Создайте новый ключ при необходимости

### Ошибка "Quota exceeded"
1. Проверьте лимиты в Google AI Studio
2. Подождите до сброса лимитов
3. Оптимизируйте настройки

### Медленные ответы
1. Используйте Gemini 1.5 Flash
2. Уменьшите maxOutputTokens
3. Проверьте интернет соединение
