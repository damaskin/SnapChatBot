# Устранение проблем с Gemini API

## 🔍 Диагностика проблемы

Ваш API ключ `AIzaSyB1fsG5NFKa7uMl50JrcToCO-fhJNPIV_k` не работает. Возможные причины:

### 1. 🚫 API не активирован
**Проблема**: Gemini API не включен в Google Cloud Console

**Решение**:
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Выберите ваш проект
3. Перейдите в **"APIs & Services"** → **"Library"**
4. Найдите **"Generative Language API"**
5. Нажмите **"Enable"** (Включить)

### 2. 🔑 Неправильный API ключ
**Проблема**: API ключ создан неправильно или устарел

**Решение**:
1. Перейдите в [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Удалите старый ключ
3. Создайте новый API ключ
4. Скопируйте новый ключ

### 3. 🌍 Региональные ограничения
**Проблема**: Gemini API может быть недоступен в вашем регионе

**Решение**:
1. Используйте VPN для доступа к Google AI Studio
2. Проверьте, доступен ли Gemini в вашей стране
3. Обратитесь в поддержку Google

### 4. 💳 Проблемы с биллингом
**Проблема**: Требуется привязанная карта для активации API

**Решение**:
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Перейдите в **"Billing"**
3. Привяжите карту (даже для бесплатного использования)
4. Активируйте Gemini API

## 🛠 Пошаговая настройка

### Шаг 1: Создание проекта
1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Нажмите **"Select a project"** → **"New Project"**
3. Введите название: `snapchat-bot-gemini`
4. Нажмите **"Create"**

### Шаг 2: Активация API
1. В боковом меню выберите **"APIs & Services"** → **"Library"**
2. В поиске введите **"Generative Language API"**
3. Нажмите на результат
4. Нажмите **"Enable"**

### Шаг 3: Создание API ключа
1. Перейдите в **"APIs & Services"** → **"Credentials"**
2. Нажмите **"+ CREATE CREDENTIALS"** → **"API key"**
3. Скопируйте созданный ключ
4. (Опционально) Ограничьте ключ для безопасности

### Шаг 4: Тестирование
```bash
# Запустите тест
node test-gemini.js
```
